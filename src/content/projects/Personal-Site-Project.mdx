Merhaba, ben **Metehan Şenyer**, Kocaeli Üniversitesi Yazılım Mühendisliği öğrencisiyim. Bu proje, projelerimi ve yeteneklerimi sergilemek amacıyla modern web teknolojileri kullanılarak oluşturduğum **Personal Site Project** adlı kişisel portfolio web sitesidir. Proje, Astro ve TypeScript kullanımı konusundaki becerilerimi sergilemek ve modern web geliştirme pratiklerini uygulama fırsatı sunmuştur.

## 🚀 Proje Hakkında

**Personal Site Project**, Astro 7 ve TypeScript kullanılarak geliştirilmiş, modern web teknolojilerini temel alan bir portfolio web sitesidir. Amacım, yalnızca teknik gereklilikleri yerine getirmek değil, aynı zamanda kullanıcı dostu ve performanslı bir web deneyimi sunmaktı. Site, Dokploy ile kendi sunucumda (Docker + nginx) barındırılmakta ve SEO optimizasyonu ile birlikte gelişmiş özellikler sunmaktadır.

## 🎯 Projenin Temel Amaçları

- **Astro 7** kullanarak hızlı, statik çıktı üreten modern bir web sitesi geliştirme
- **TypeScript** ile tip güvenliği sağlama
- **Responsive Design** ile her cihaza uyumlu tasarım (Mobil geliştirmesi sürmekte)
- **SEO Optimizasyonu** ile arama motoru görünürlüğünü artırma
- **Markdown Integration** ile dinamik içerik yönetimi

## 💾 İndirme ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

### Ön koşullar

- Node.js (v22 veya üstü)
- pnpm

### Kurulum

1. **Depoyu klonlayın:**

   ```bash
   git clone https://github.com/metehansenyer/Personal-Site-Project.git
   ```

2. **Proje dizinine gidin:**

   ```bash
   cd Personal-Site-Project
   ```

3. **Bağımlılıkları yükleyin:**
   ```bash
   pnpm install
   ```

### Uygulamayı Çalıştırma

- **Geliştirme modu:**

  ```bash
  pnpm dev
  ```

  Tarayıcıda görüntülemek için [http://localhost:4321](http://localhost:4321) adresini açın.

- **Production build:**

  ```bash
  pnpm build
  ```

- **Production çıktısını yerelde önizleyin:**
  ```bash
  pnpm preview
  ```
