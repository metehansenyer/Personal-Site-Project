Hi, I'm **Metehan Şenyer**, a Software Engineering student at Kocaeli University. This project is the **Minesweeper game**, which I built for the **Programming Laboratory III** course in the 2024-2025 term. It is a minesweeper game written in C# and built on OOP principles.

## 🚀 About the Project

The **Minesweeper game** is a minesweeper game written in C# and built on OOP principles. My aim was not just to meet the technical requirements, but also to deliver a fun and engaging game experience. The project was developed with Visual Studio, and the game was built using Windows Forms.

## 🎯 Main Goals of the Project

- Applying OOP principles using the **C# programming language**.
- Developing **minesweeper algorithms** and game mechanics.
- Creating the game's visual design using **WinForms**.
- Enriching the user experience beyond the technical requirements with details like a **score system**, **visuals** and a **GUI**.

## 🎮 Gameplay Mechanics

| Mechanic | Description |
| :-------------: | :---------------------------------------------------------------------------------: |
| Revealing Cells | Left-click to reveal cells and see the numbers on cells that aren't mines. |
| Placing Flags | Right-click to place a flag on cells you think are mines. |
| Auto-Reveal | When you click an empty cell, the mine-free cells around it open automatically. |
| Score System | Place flags correctly and finish quickly to earn a high score. |

## 📊 Technical Details

Here are the details of the project:

- **Classes**: Designed following OOP principles to make the structure of the game modular and extensible.
  1. There are core classes such as Cell, Board and Game.
  2. The ScoreManager and GameState classes manage the game state.
- **Mine Placement Algorithm**:
  1. Mines are placed randomly when the game starts
  2. The first click is guaranteed not to hit a mine
  3. The number of neighboring mines is calculated for each cell
- **Game Logic**:
  1. Opening empty cells with a flood-fill algorithm
  2. Flag system and mine checking
  3. Win/loss condition checking
- **Data Management**:
  1. Storing and ranking high scores
  2. Saving the game state
  3. Persisting settings
