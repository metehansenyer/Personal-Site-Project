Hi, I'm **Metehan Şenyer**, a Software Engineering student at Kocaeli University. This project is the **Spacewar game**, which I built for the **Programming Laboratory III** course in the 2024-2025 term. It gave me a chance to show off my software development skills and apply OOP (Object-Oriented Programming) principles in a real project.

## 🚀 About the Project

The **Spacewar game** is a space battle game written in C# and built on OOP principles. My aim was not just to meet the technical requirements, but also to deliver a fun and engaging game experience. The project was developed with JetBrains Rider and tested on MacOS.

## 🎯 Main Goals of the Project

- Applying OOP principles (inheritance, polymorphism, encapsulation) using the **C# programming language**.
- Developing **collision algorithms** and game mechanics.
- Enriching the user experience beyond the technical requirements with details like **sound effects**, **visuals** and a **GUI**.

## 🎮 Gameplay Mechanics

| Mechanic | Description |
| :------------------: | :---------------------------------------------------------------------------: |
| Player Movement | Steer the spaceship to dodge enemies and fire back. |
| Collision Algorithm | Detects collisions between bullets and ships and triggers the necessary actions. |
| Score System | Grants advantages such as extra lives, speed and damage. |
| Power-Ups | The difficulty level rises according to the player's performance. |

## 📊 Technical Details

Here are the details of the project:

- **Classes**: Designed following OOP principles to make the structure of the game modular and extensible.
  1. There are classes such as Spaceship, Enemy and Bullet.
- **Collision Algorithms**: Collisions are checked using custom algorithms (circle intersection, point-in-triangle test).
- **Game Flow**: The start, update and end phases are managed with a clean and efficient game loop.
