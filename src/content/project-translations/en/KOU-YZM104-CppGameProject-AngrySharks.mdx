Hi, I'm **Metehan Şenyer**, a Software Engineering student at Kocaeli University. This project is the **Angry Sharks game**, which I built for the **Programming 2** course in the 2023-2024 term. It gave me a chance to show off my C++ skills and apply object-oriented programming principles in a real project.

## 🦈 About the Project

**Angry Sharks** is a 2D game written in C++ and built on object-oriented programming principles. My aim was not just to meet the technical requirements, but also to deliver a fun and engaging game experience. The project was developed with the CLion IDE and tested on both MacOS and Windows.

## 🎯 Main Goals of the Project

- Applying object-oriented programming principles using the **C++ programming language**
- 2D game development with the **Raylib library**
- Enriching the user experience beyond the technical requirements with details like **sound effects**, **visuals** and **game mechanics**

## 🎮 Game Features

| Feature | Description |
| :---------------: | :---------------------------------------: |
| Character Control | Steering and rotating the character with the mouse |
| Collision System | Advanced collision detection mechanism |
| Level System | Character growth and progression mechanics |
| Sound Effects | In-game sound and music system |

## 📊 Technical Challenges and Solutions

| Challenge | Solution Approach |
| :--------------------: | :------------------------------------------------------------: |
| Movement System | Mouse tracking and angular rotation calculations |
| Collision Detection | Circle-based collision system and origin point optimization |
| Sound System | Raylib sound system integration |
| Character Sizing | Level-based character scaling |
