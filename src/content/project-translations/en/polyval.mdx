Hi, I'm **Metehan Şenyer**. This project is **PolyVal**, a multilingual, highly customizable validation library that gives developers a simplified API while using Zod under the hood.

## 🚀 About the Project

**PolyVal** was built to be easy to use, without requiring complex type definitions or knowledge of validation rules. It offers a strong solution especially for multilingual projects and for cases where customized error messages are needed.

## 🎯 Main Goals of the Project

- **Simplified API**: Letting developers validate data without wrestling with complex definitions.
- **Multilingual Support**: Providing default support for `en` (English) and `tr` (Turkish).
- **Flexible Error Messages**: Being able to fully customize error messages per field, per rule type, or globally.
- **Custom Rules**: Letting developers easily define their own validation rules.
- **TypeScript Support**: Offering a fully type-safe development experience.

## 🚀 Basic Usage

```typescript
import { validate } from 'polyval'

// Simple schema definition
const userSchema = {
  username: {
    type: 'string',
    required: true,
    min: 3,
    max: 20,
  },
  email: {
    type: 'string',
    required: true,
    email: true,
  },
  age: {
    type: 'number',
    min: 18,
  },
}

// Data to validate
const userData = {
  username: 'jo',
  email: 'invalid-email',
  age: 16,
}

// Validation (in Turkish)
const errors = validate(userSchema, userData, { lang: 'tr' })
console.log(errors)
// [
//   "Username: En az 3 karakter uzunluğunda olmalıdır",
//   "Email: Geçersiz e-posta adresi",
//   "Age: En az 18 olmalıdır"
// ]
```

## 📝 Defining Schemas

PolyVal schemas are defined using plain JavaScript objects. Each field uses a configuration object:

```typescript
const schema = {
  fieldName: {
    type: 'string' | 'number' | 'boolean' | 'date', // Field type (required)
    required: boolean, // Is the field required? (default: false)
    // Other validation rules...
  },
}
```

### Supported Validation Rules

#### For String Fields

```typescript
{
  type: 'string',
  required: boolean,           // Required?
  min: number,                 // Minimum length
  max: number,                 // Maximum length
  length: number,              // Exact length
  email: boolean,              // Email format
  url: boolean,                // URL format
  uuid: boolean,               // UUID format
  cuid: boolean,               // CUID format
  datetime: boolean,           // ISO 8601 date-time format
  ip: 'v4' | 'v6',             // IP address format
  regex: string,               // Regex pattern (as a string)
  startsWith: string,          // Must start with this value
  endsWith: string,            // Must end with this value
  numeric: boolean             // Numeric characters only
}
```

#### For Number Fields

```typescript
{
  type: 'number',
  required: boolean,           // Required?
  min: number,                 // Minimum value
  max: number                  // Maximum value
}
```

#### For Date Fields

```typescript
{
  type: 'date',
  required: boolean,           // Required?
  min: number,                 // Minimum date (timestamp)
  max: number                  // Maximum date (timestamp)
}
```

#### For Boolean Fields

```typescript
{
  type: 'boolean',
  required: boolean,           // Required?
  equals: boolean              // Should it be equal to a specific value (true/false)?
}
```

### Field Comparison Rules

To validate a field against another field:

```typescript
{
  password: {
    type: 'string',
    required: true,
    min: 8
  },
  confirmPassword: {
    type: 'string',
    required: true,
    equals: 'password'         // Must match the 'password' field
  },
  oldPassword: {
    type: 'string',
    required: true,
    notEquals: 'password'      // Must not match the 'password' field
  }
}
```

### Custom Validation Rules

To define your own validation logic:

```typescript
{
  username: {
    type: 'string',
    required: true,
    customValidators: [
      {
        validator: (value, data) => {
          // Alphanumeric character check
          if (!/^[a-zA-Z0-9]+/.test(value)) {
            return 'Sadece harf ve rakam kullanabilirsiniz';
          }
          // Admin name check
          if (value.toLowerCase() === 'admin') {
            return 'Bu kullanıcı adı kullanılamaz'; // Return the error message
          }
          return undefined; // Return undefined for a successful validation
        },
        messageKey: 'noAdminUsername'  // Key used for custom messages
      }
    ]
  }
}
```

## 🎨 Customizing Error Messages

PolyVal lets you fully customize error messages:

```typescript
const errors = validate(schema, data, {
  lang: 'tr',
  customMessages: {
    // 1. Global error messages
    required: 'Bu alan boş bırakılamaz',
    invalid_type: 'Geçersiz değer türü',

    // 2. Type-based error messages
    string: {
      min: (min) => `Lütfen en az ${min} karakter girin`,
      email: 'Lütfen geçerli bir e-posta adresi girin',
    },
    number: {
      min: (min) => `Değer en az ${min} olmalıdır`,
    },

    // 3. Custom comparison rule messages
    equals: (field) => `Bu alan, ${field} alanı ile eşleşmelidir`,

    // 4. Field-based custom messages (highest priority)
    fields: {
      username: {
        min: (min) => `Kullanıcı adı en az ${min} karakter olmalıdır`,
        required: 'Kullanıcı adı zorunludur',
        // Message for a custom validation rule
        noAdminUsername: 'Admin kullanıcı adı rezerve edilmiştir',
      },
    },

    // 5. Global custom validator messages
    custom: {
      noAdminUsername: 'Admin kullanıcı adı kullanılamaz',
    },
  },
})
```

### Message Priority Order

Error messages are resolved in the following order of priority (highest to lowest):

1.  Field-based custom validator messages (`customMessages.fields['fieldName']['customMessageKey']`)
2.  Other field-based custom messages (`customMessages.fields['fieldName']['min']`)
3.  Global custom validator messages (`customMessages.custom['messageKey']`)
4.  Global rule-based custom messages (`customMessages.string.email`, `customMessages.number.min`)
5.  Global error type messages (`customMessages.required`, `customMessages.invalid_type`)
6.  Default messages in the selected language

## 🌟 Comprehensive Examples

### User Registration Validation Example

```typescript
import { validate } from 'polyval'

// User registration schema
const userRegistrationSchema = {
  username: {
    type: 'string',
    required: true,
    min: 3,
    max: 20,
    customValidators: [
      {
        validator: (value) =>
          value.toLowerCase() !== 'admin' ? undefined : 'Admin kullanıcı adı kullanılamaz',
        messageKey: 'noAdminUsername',
      },
    ],
  },
  email: {
    type: 'string',
    required: true,
    email: true,
  },
  age: {
    type: 'number',
    min: 18,
    required: false,
  },
  password: {
    type: 'string',
    required: true,
    min: 8,
    max: 100, // Minimum/maximum length check for a strong password
  },
  confirmPassword: {
    type: 'string',
    required: true,
    equals: 'password', // Must match the 'password' field
    customValidators: [
      {
        validator: (value, data) =>
          value !== data.password + '123' ? undefined : 'Tahmin edilebilir bir şifre kullandınız',
        messageKey: 'predictablePassword',
      },
    ],
  },
  acceptTerms: {
    type: 'boolean',
    required: true,
    equals: true, // The user must accept the terms
  },
}

// Invalid data
const userData = {
  username: 'al',
  email: 'invalid-email',
  password: '123',
  confirmPassword: '456',
  acceptTerms: false,
}

// Validation with Turkish error messages
const errorsTR = validate(userRegistrationSchema, userData, { lang: 'tr' })
console.log(errorsTR)

// Validation in English with customized messages
const errorsEN = validate(userRegistrationSchema, userData, {
  lang: 'en',
  customMessages: {
    string: {
      min: (min) => `Please ensure this field has at least ${min} characters.`,
      email: "That doesn't look like a valid email address.",
    },
    fields: {
      username: {
        noAdminUsername: "Sorry, 'admin' is a reserved username.",
      },
      confirmPassword: {
        equals: 'Passwords must match exactly.',
      },
    },
  },
})

console.log(errorsEN)
```
