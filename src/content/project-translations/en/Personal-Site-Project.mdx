Hi, I'm **Metehan Şenyer**, a Software Engineering student at Kocaeli University. This project is **Personal Site Project**, my personal portfolio website, built with modern web technologies to showcase my projects and skills. It gave me a chance to show what I can do with Astro and TypeScript and to put modern web development practices into use.

## 🚀 About the Project

**Personal Site Project** is a portfolio website built with Astro 7 and TypeScript, based on modern web technologies. My goal was not just to meet the technical requirements, but also to deliver a user-friendly and performant web experience. The site is hosted on my own server with Dokploy (Docker + nginx) and comes with SEO optimization and advanced features.

## 🎯 Main Goals of the Project

- Building a fast, modern website that produces static output with **Astro 7**
- Providing type safety with **TypeScript**
- A design that fits every device with **Responsive Design** (mobile development is still in progress)
- Improving search engine visibility with **SEO Optimization**
- Dynamic content management with **Markdown Integration**

## 🛠️ Tools Used

I made use of the following tools and resources throughout the project:

<Icon />

- **Astro**: A web framework that produces static output and sends almost no JavaScript to the client (no UI framework is used)
- **TypeScript**: A typed superset of JavaScript that compiles to plain JavaScript
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development
- **Font Awesome**: For icons.
- **Markdown & MDX**: For type-safe project content with content collections
- **Docker & Dokploy**: For packaging as a Docker image and for hosting/deploying on my own server

## 💾 Download and Run

To run the project in your local environment, you can follow these steps:

### Prerequisites

- Node.js (v22 or later)
- pnpm

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/metehansenyer/Personal-Site-Project.git
   ```

2. **Go to the project directory:**

   ```bash
   cd Personal-Site-Project
   ```

3. **Install the dependencies:**
   ```bash
   pnpm install
   ```

### Running the Application

- **Development mode:**

  ```bash
  pnpm dev
  ```

  Open [http://localhost:4321](http://localhost:4321) to view it in your browser.

- **Production build:**

  ```bash
  pnpm build
  ```

- **Preview the production output locally:**
  ```bash
  pnpm preview
  ```
