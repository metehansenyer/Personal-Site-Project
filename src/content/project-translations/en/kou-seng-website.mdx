Hi, I'm **Mete**, a Software Engineering student at Kocaeli University. This project is the official website of the Kocaeli University Software Community (SENG). As part of the web team, I played an active role in developing it.

## About the Project

**KOU SENG Website** is a modern and user-friendly platform aimed at both club members and prospective members. The site includes the club's announcements, events and introductions of its technical teams. It also offers a comprehensive application system that lets new members apply online.

## 🎯 Main Goals of the Project

- **Introducing the Club**: Presenting the SENG club and its technical teams
- **Membership Management**: Managing online applications and membership processes
- **Announcement System**: Sharing the club's announcements dynamically
- **Easy Communication**: Communicating effectively with visitors
- **Responsive Design**: Delivering a great user experience on every device

## Project Structure

This project consists of two main parts:

### Backend

- **Technology**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT Token
- **API Endpoints**: RESTful API

### Frontend

- **Technology**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/ui, FontAwesome
- **State Management**: React Hooks
- **Form Management**: React Hook Form + Zod

## Features

- Responsive design (mobile, tablet, desktop)
- Comprehensive management interface with an admin panel
- Online management of new membership applications
- Dynamic sharing of the club's announcements
- An effective contact form for communicating with visitors
- Introduction pages for the AI, Game and Web development teams
- RSS Feed integration
- Dark/Light theme support

## 📋 Requirements

- Node.js
- MongoDB
- npm

## 🚀 Installation and Running

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
