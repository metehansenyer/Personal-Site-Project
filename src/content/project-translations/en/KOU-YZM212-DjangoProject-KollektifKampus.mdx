Hi, I'm **Metehan Şenyer**. This project is **KollektifKampus**, a peer learning platform we developed for the Web Programming course in the Software Engineering Department at Kocaeli University. It shows our skills in building a modern and interactive web application with the Django framework.

## 🚀 About the Project

**KollektifKampus** is a platform that aims to make it easier for university students to learn from each other and share knowledge. On this platform, students can create course requests, sign up as tutors, and take an active role in the community by helping other students.

## 🎯 Main Goals of the Project

- Building a comprehensive web application with the **Django Framework**.
- Creating **different user roles** (Student, Tutor, Moderator) and authorization systems.
- Providing full **CRUD (Create, Read, Update, Delete)** operations on the database.
- Improving the user experience with **advanced search and filtering** features.
- Making data management easier with **data import/export** functionality.

## 💾 Download and Run

To run the project in your local environment, you can follow these steps:

1.  Clone the repo:

    ```bash
    git clone https://github.com/metehansenyer/KOU-YZM212-DjangoProject-KollektifKampus.git
    cd KollektifKampus
    ```

2.  Create and activate a virtual environment:

    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # macOS / Linux
    source venv/bin/activate
    ```

3.  Install the required packages:

    ```bash
    pip install -r requirements.txt
    ```

4.  Apply the database migrations:

    ```bash
    python manage.py migrate
    ```

5.  Start the development server:

    ```bash
    python manage.py runserver
    ```

6.  You can access the application by going to `http://127.0.0.1:8000/` in your browser.
