# KOU SENG Website

Merhaba, ben **Mete**, Kocaeli Üniversitesi Yazılım Mühendisliği öğrencisiyim. Bu proje, Kocaeli Üniversitesi Yazılım Kulübü'nün (SENG) resmi web sitesidir. Web takımının bir parçası olarak bu projenin geliştirilmesinde aktif rol aldım.

## Proje Hakkında

**KOU SENG Website**, kulüp üyelerine ve potansiyel üyelere hitap eden modern ve kullanıcı dostu bir platformdur. Site, kulübün duyurularını, etkinliklerini ve teknik ekip tanıtımlarını içermektedir. Ayrıca yeni üyelerin online başvuru yapabilmesini sağlayan kapsamlı bir başvuru sistemi sunmaktadır.

## 🎯 Projenin Temel Amaçları

- **Kulüp Tanıtımı**: SENG kulübünü ve teknik ekiplerini tanıtmak
- **Üyelik Yönetimi**: Online başvuru ve üyelik süreçlerini yönetmek
- **Duyuru Sistemi**: Kulüp duyurularını dinamik olarak paylaşmak
- **İletişim Kolaylığı**: Ziyaretçilerle etkili iletişim sağlamak
- **Responsive Tasarım**: Tüm cihazlarda mükemmel kullanıcı deneyimi sunmak

## Proje Yapısı

Bu proje iki ana bölümden oluşmaktadır:

### Backend

- **Teknoloji**: Node.js, Express.js
- **Veritabanı**: MongoDB
- **Kimlik Doğrulama**: JWT Token
- **API Endpoints**: RESTful API

### Frontend

- **Teknoloji**: Next.js, React, TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/ui, FontAwesome
- **State Management**: React Hooks
- **Form Management**: React Hook Form + Zod

## Özellikler

- Responsive tasarım (mobil, tablet, desktop)
- Admin paneli ile kapsamlı yönetim arayüzü
- Yeni üyelik başvurularının online yönetimi
- Kulüp duyurularının dinamik paylaşımı
- Ziyaretçilerle etkili iletişim formu
- AI, Game ve Web geliştirme ekiplerinin tanıtım sayfaları
- RSS Feed entegrasyonu
- Koyu/Açık tema desteği

## 📋 Gereksinimler

- Node.js
- MongoDB
- npm

## 🚀 Kurulum ve Çalıştırma

### Backend Kurulumu

```bash
cd backend
npm install
npm run dev
```

### Frontend Kurulumu

```bash
cd frontend
npm install
npm run dev
```
